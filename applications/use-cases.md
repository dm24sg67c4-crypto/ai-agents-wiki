# Agent 能做什麼：應用實例

> 數字提醒：下列效益數字多為廠商或客戶自述，標示「據該文」，未經獨立驗證（見 S5 可信度備註）。

## 最常被提到的兩個場景

- **客服**：對話加上行動、成功可衡量 [S1.10]；agent 可預判需求、主動處理，必要時升級給人類，也能直接開立工單或處理退款 [S5.5]。
- **軟體開發**：結果可用自動化測試驗證，但人工審查仍然重要 [S1.10]。給定 ticket 或 bug 報告，agent 可探索程式碼庫、找相關檔案並跑測試 [S5.9]；據該文，IBM 的 Bob 讓開發者生產力提升 45% [S5.9]。

## 其他產業（據 IBM 文章）

- **金融**：持續詐欺偵測、合規監控、貸款審核 [S5.6]；引用的報告稱試點節省約 30,000 工作天、行政類工作生產力提升 20%–59% [S5.6]。
- **醫療**：處理帳單與排程等行政工作，並自動化事先授權與遠端病患監測 [S5.7]。
- **法律**：據報導讓文件審閱、研究與起草平均時間減少約三分之一 [S5.8]。
- **教育**：個人化學習路徑、研究助理、模擬面試或外語對話 [S5.10]。
- **人資**：據稱 AskHR 完全自動化 80 多種常見人資請求 [S5.11]。

## 研究與科學

ChemCrow 為 LLM 配上專家設計的工具，處理有機合成、藥物探索等任務；Generative Agents 則用 LLM 模擬 25 個虛擬角色 [S3.11]。

## 什麼樣的任務適合 Agent

- 複雜決策、規則難以維護、大量非結構化資料 [S2.4]。
- 有明確成功標準、可建立回饋迴圈、並保有人類監督 [S1.10]。
