# Agent 迴圈：思考 → 行動 → 觀察

## 核心概念：一個 while 迴圈

- OpenAI 指出，agent 的每次執行（run）通常實作成迴圈，持續到退出條件成立為止 [S2.7]。
- Anthropic 也說 agent 的實作往往很單純：就是 LLM 根據環境回饋，在迴圈中使用工具 [S1.7]。

## ReAct：最經典的迴圈樣式

- ReAct 讓模型交錯產生推理軌跡與行動：推理協助建立、追蹤、更新計畫並處理例外，行動則連接外部來源取得資訊 [S4.1]。
- 提示格式大致是 Thought、Action、Observation 重複許多輪 [S3.3]。
- 在問答與事實驗證任務上，這種作法克服了純 Chain of Thought 的幻覺與錯誤傳遞 [S4.2]，也讓過程更容易解讀 [S4.4]。

```
任務 → 思考(Thought) → 行動(Action) → 觀察(Observation) ─┐
          ↑─────────────────────────────────────────────┘
          直到：完成 / 出錯 / 達到最大回合數
```

## 每一輪都要「對照現實」

Anthropic 強調，執行時每一步都要從環境取得 ground truth（例如工具回傳結果、程式執行結果）來評估進度 [S1.6]。

## 什麼時候停下來

- 常見退出條件：呼叫最終輸出工具、模型回覆中沒有工具呼叫、發生錯誤、達到最大回合數 [S2.7]。
- 也常設定停止條件（例如最大迭代次數）以維持控制，並可在檢查點或遇到阻礙時暫停詢問人 [S1.6]。

## 另一種迴圈：生成 ↔ 評估

evaluator-optimizer 讓一個 LLM 生成、另一個評估並回饋，形成迴圈 [S1.4]；適合有明確評估標準、且反覆修正有可衡量價值的情況 [S1.5]。
