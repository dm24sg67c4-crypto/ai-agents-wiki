# 工具（Tools）

## 為什麼需要工具

- 工具讓 agent 呼叫外部 API，補足模型權重裡缺少的資訊，例如最新資訊、執行程式的能力、私有資料來源 [S3.6]。
- 有了工具，agent 才能突破訓練資料的限制 [S5.3]。

## 工具的三種類型

OpenAI 把工具分成三類 [S2.6]：

1. **Data**：取得脈絡資訊，例如查資料庫、讀 PDF、搜尋網頁。
2. **Action**：對系統採取行動，例如寄信、更新紀錄、把工單轉給人類。
3. **Orchestration**：agent 本身可以被當作別的 agent 的工具。

## 工具要設計得好

- 因為 agent 靠工具與環境互動，所以工具集與工具文件的設計非常關鍵 [S1.7]。
- Anthropic 建議用完整的文件與測試來精心設計 agent-computer interface [S1.9]。

## 模型要「知道何時、如何」用工具

- MRKL 架構讓 LLM 當路由器，把請求分派給最適合的專家模組 [S3.7]。
- 實驗顯示，知道何時以及如何使用工具是關鍵，取決於 LLM 本身的能力 [S3.8]。
