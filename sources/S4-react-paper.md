# S4｜Yao 等〈ReAct: Synergizing Reasoning and Acting in Language Models〉

- **網址**：https://arxiv.org/abs/2210.03629
- **發表**：arXiv 2022-10-06，最終版為 ICLR 2023
- **來源類型**：同儕審查學術論文
- **抓取日期**：2026-11-21
- **抓取範圍**：僅摘要頁（未讀全文）；Thought／Action／Observation 的具體格式請見 [S3.3]

## 要點（引用時請用編號，例如 [S4.1]）

- **S4.1** ReAct 讓語言模型以「交錯」的方式同時產生推理軌跡與任務專屬的行動：推理幫助模型建立、追蹤、更新行動計畫並處理例外；行動則讓模型連接外部來源（如知識庫或環境）取得額外資訊。
- **S4.2** 在問答（HotpotQA）與事實驗證（Fever）任務上，ReAct 透過簡單的 Wikipedia API 互動，克服了純 Chain of Thought 推理中常見的幻覺與錯誤傳遞，並產生比沒有推理軌跡的基準更容易解讀的任務解決過程。
- **S4.3** 在兩個互動決策基準（ALFWorld、WebShop）上，ReAct 的成功率分別比模仿學習與強化學習方法絕對高出 34% 與 10%，而且只用一兩個範例提示。
- **S4.4** 論文主張這種作法同時提升了人類對結果的可解釋性與可信度。

學術一手資料，是「推理與行動交錯迴圈」的原始出處；本頁僅依摘要整理，數字（34%、10%）取自摘要。
