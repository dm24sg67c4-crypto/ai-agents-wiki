# S5｜IBM〈AI agent use cases〉

- **網址**：https://www.ibm.com/think/topics/ai-agent-use-cases
- **發表**：2025-04-15（作者 Molly Hayes、Amanda Downie，IBM Think）
- **來源類型**：廠商（IBM）科普與應用整理
- **抓取日期**：2026-11-21
- **在 Wiki 中的角色**：應用實例、與聊天機器人的差別

## 要點（引用時請用編號，例如 [S5.4]）

- **S5.1** IBM 認為 AI agent 能規劃、做決策、使用工具、保留上下文並完成多步驟任務，比聊天機器人更像「數位同事」。
- **S5.2** 相較於過去以單一任務運作的助理與聊天機器人，agentic AI 能自主規劃、推理並執行複雜任務，所需的人為介入較少。
- **S5.3** agent 以 LLM 為基礎，可呼叫工具與 API 來突破訓練資料的限制；與一般聊天機器人不同，agent 會跨互動儲存記憶，長期改善推理與準確度。
- **S5.4** IBM 列出五種 agent 類型：simple reflex、model-based reflex、goal-based、utility-based、learning。其中 simple reflex 只依單一規則行動，沒有記憶，資訊不足時也不會詢問其他 agent。
- **S5.5** 客服：傳統聊天機器人依預設腳本回應，agent 則能預判需求並主動採取行動，複雜問題會自動升級給人類，也能直接開立工單或處理退款。
- **S5.6** 金融：可做持續性的詐欺偵測、合規監控與貸款審核；文中引用世界經濟論壇報告，指出一批試點節省約 30,000 個工作天，行政、文件與初步分析的生產力提升 20%–59%。
- **S5.7** 醫療：agent 可處理帳單、排程等行政工作，並自動化事先授權、遠端病患監測等例行任務。
- **S5.8** 法律：Thomson Reuters 的 agent 助理據報導讓文件審閱、研究與起草的平均時間減少約三分之一。
- **S5.9** 軟體開發：給定 ticket 或 bug 報告，agent 可探索程式碼庫、找出相關檔案並執行測試；IBM 自家工具 Bob 有 10,000 名 IBM 開發者使用，據稱讓開發者生產力提升 45%。
- **S5.10** 教育：agent 可提供個人化學習路徑、協助整理資料的研究助理，以及模擬面試或外語對話的練習情境。
- **S5.11** 人資：IBM 的 AskHR 據稱完全自動化了 80 多種常見人資請求。
